# 指令集

| 指令号 |    指令    | 说明                                              |       指令格式       | 对应16进制数 |
| :----: | :--------: | ------------------------------------------------- | :------------------: | :-----------: |
|   1   |   设备ID   | FPGA从机的设备ID                                  | 1111_1111_1111_1110B |    0xFFFE    |
|   2   |  读设备ID  | 让从机返回设备的ID，在下次通信放回SPI的ID         | 1111_1111_1111_1111B |    0xFFAF    |
|   3   | 开始某操作 | 开始某种操作，不包括数据交换，XXX表示第XXXB个操作 | 1111_1111_1010_1XXXB | 0xFFA8~0xFFAF |
|   4   | 结束某操作 | 结束某种操作，不包括数据交换，XXX表示第XXXB个操作 | 1111_1111_1010_0XXXB | 0xFFA0~0xFFA7 |
|   3   | 开始某操作 | 开始某种操作，包括数据交换，XXX表示第XXXB个操作   | 1111_1111_1010_1XXXB | 0xFFB8~0xFFBF |
|   4   | 结束某操作 | 结束某种操作，包括数据交换，XXX表示第XXXB个操作   | 1111_1111_1010_0XXXB | 0xFFB0~0xFFB7 |

# 指令具体收发顺序

## 1. 读设备ID

1. 在第一次通信发送读取设备ID的指令
2. 开启第二次的通信，从机返回设备ID
3. 上位机根据读到的设备ID判断是否正确
4. 设备ID正确，可以开启后续控制

## 2. 开启某操作

1. 在第一次通信发送开启某操作指令，XXX包含8个特殊指令
2. 在后续通信发送某操作所需的数据包

### 操作1：设置时钟频率及相位（基频50MHz）

数据包格式：

1. 发送开启操作1（0xFFA9）
2. 发送需要调整的通道数量（如：有三路，我需要调整1，3路，0x0002）
3. 发送全部时钟倍频的整数部分+小数部分（如：我想倍频8.250倍，0x087D)，小数部分只能是125的倍数
4. 发送全部时钟的整数分频部分（如：我想分频4，0x0400)
5. 发送0x0001表示选择时钟1
6. 发送时钟1的分频数，注意时钟1有小数分频（如：我想分频1.250，0x017D)
7. 发送0x0003表示选择时钟3
8. 发送时钟3的分频数如5，没有小数分频（如：我想分频2，0x0200）
9. 发送0x0001表示选择时钟1
10. 发送相位（如：我想移位180°，0x00B4）
11. 发送0x0003表示选择时钟3
12. 发送相位（如：我想移位180°，0x00B4）

### 操作2：读取ADC

1. 发送开启操作2 （0xFFAA）
2. 接收16位ADC数据
3. 发送结束操作2（0xFFA2)

### 操作3：输出DAC

1. 发送开启操作3（0xFFAB）
2. 发送16位DAC数据
3. 发送结束操作3（0xFFA3）

### 操作4：开启ADC端的FIR低通滤波

1. 发送开启操作4（0xFFAC）
2. ADC数据会经过FIR再发送给32
3. 发送结束操作4（0xFFA4)

### 操作5：开启DAC端的FIR低通滤波

1. 发送开启操作4（0xFFAD）
2. ADC数据会经过FIR再发送给32
