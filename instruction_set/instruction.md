|          指令          | 说明                                                                                                              | 指令格式   |
| :--------------------: | ----------------------------------------------------------------------------------------------------------------- | ---------- |
|         设备ID         | FPGA从机的设备ID                                                                                                  | 1000_1000B |
|        读设备ID        | 让从机返回设备的ID                                                                                                | 1111_1111B |
|        写寄存器        | 向指定地址的寄存器写入数据                                                                                        | 1000_1000B |
|        读寄存器        | 读取指定地址的寄存器值                                                                                            | 1000_1001B |
|      连续写寄存器      | 从起始地址开始连续写入多个寄存器，其中XXX表示连续写入的个数，范围为000-111，表示1-8个数，地址为指定地址的后XXXB位 | 1XXX_1000B |
|      连续读寄存器      | 从起始地址开始连续读取多个寄存器，其中XXX表示连续读出的个数，范围为000-111，表示1-8个数，地址为指定地址的后XXXB位 | 1XXX_1001B |
| **读寄存器状态** | 读取设备中已存储的数据的个数，在第二次通信的时候返回                                                              | 1000_1111B |
|       开始某操作       | 开始某种操作，可以是开始ADC读取、或者开始数据处理等，XXX表示第XXXB个操作                                          | 1XXX_1100B |
|       结束某操作       | 结束某种操作，可以是暂停ADC读取、或者停止数据处理等，XXX表示第XXXB个操作                                          | 0XXX_1100B |
|    设置设备时钟频率    | 控制由FPGA驱动的设备，如ADC、DAC等设备的时钟频率，采样率等，其中Z为0表示分频，1表示倍频，XXX表示分/倍频的大小     | ZXXX_1110B |
