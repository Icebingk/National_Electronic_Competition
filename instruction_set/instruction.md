# 指令集

| 指令号 |          指令          | 说明                                                                                                         |  指令格式  |
| :----: | :--------------------: | ------------------------------------------------------------------------------------------------------------ | :--------: |
|   1   |         设备ID         | FPGA从机的设备ID                                                                                             | 1000_1000B |
|   2   |        读设备ID        | 让从机返回设备的ID，在下次通信放回SPI的ID                                                                    | 1111_1111B |
|   3   |        写寄存器        | 向指定地址的寄存器写入数据                                                                                   | 1000_1000B |
|   4   |        读寄存器        | 读取指定地址的寄存器值                                                                                       | 1000_1001B |
|   5   |      连续写寄存器      | 从起始地址开始连续写入多个寄存器，其中X若为1表示连续写入的开始，若为0表示连续写入的停止                      | 10X1_1000B |
|   6   |      连续读寄存器      | 从起始地址开始连续读取多个寄存器，其中X若为1表示连续读出的开始，若为0表示连续读出的停止                      | 10X1_1001B |
|   7   | **读寄存器状态** | 读取设备中已存储的数据的个数，在第二次通信的时候返回                                                         | 1000_1111B |
|   8   |       开始某操作       | 开始某种操作，可以是开始ADC读取、或者开始数据处理等，XXX表示第XXXB个操作                                     | 1XXX_1100B |
|   9   |       结束某操作       | 结束某种操作，可以是暂停ADC读取、或者停止数据处理等，XXX表示第XXXB个操作                                     | 0XXX_1100B |
|   10   |    设置设备时钟频率    | 控制由FPGA驱动的设备，如ADC、DAC等设备的时钟频率，采样率等，其中Z为0表示分频，1表示倍频，XXX表示第XXXB个设备 | ZXXX_1010B |

# 指令具体收发顺序

## 1. 读设备ID

1. 在第一次通信发送读取设备ID的指令
2. 开启第二次的通信，从机返回设备ID
3. 上位机根据读到的设备ID判断是否正确
4. 开启第三次通信，进行具体通信操作

## 2. 写寄存器

1. 在第一次通信发送写寄存器操作指令
2. 开启第二次通信，发送要写入的寄存器地址，若后续地址设置为16位，则分高低俩次写入
3. 开启第三次通信，发送要写入的数据

## 3. 读寄存器

1. 在第一次通信发送读寄存器操作指令
2. 开启第二次通信，发送要读出的寄存器地址，若后续地址设置为16位，则分高低俩次写入
3. 开启第三次通信，获取从机发送的数据

## 4. 连续写寄存器

1. 在第一次通信发送连续写寄存器操作指令
2. 开启第二次通信，发送要写入的寄存器的地址
3. 开启后n次通信，n为要写入的数据的个数，写入数据，地址为基地址后递增
4. 开启第n+3次通信，发送停止连续写入指令，从机停止接收数据

## 5. 连续读寄存器

1. 在第一次通信发送连续读寄存器操作指令
2. 开启第二次通信，发送要读出的寄存器的地址
3. 开启后n次通信，n为要读出的数据的个数，获取数据，地址为基地址后递增
4. 开启第n+3次通信，发送停止连续读出的指令，从机停止发送数据

## 6. 读寄存器状态

1. 在第一次通信发送读取寄存器状态指令
2. 开启第二次通信，获取寄存器状态

## 7. 开启某操作

1. 在第一次通信发送开启某操作指令，XXX包含8个特殊指令
2. 可继续发送指令
3. 完成可发送关闭某操作指令

## 8. 设置外设备时钟频率

1. 在第一次通信发送控制外设备时钟指令，其中Z控制倍频或分频，XXX表示设备序号
2. 开启第二次通信，发送倍频或者分频的大小
